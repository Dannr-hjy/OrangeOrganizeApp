# OrangeOrganize（橙子课表）

一款纯本地、无广告、无账号的 Android 课表 App。基于 **Jetpack Compose + Material3 + Room** 构建，数据全部保存在设备本地，不联网、不上传。

- 包名：`com.dannr.chengzikb`
- 当前版本：`1.5.1`（versionCode `8`）
- 最低支持：Android 8.0（API 26） / 目标：Android 15（API 35）

## 功能特性

### 1.5.1 更新

- 连堂时长与当前作息不同的节次块（WakeUp 的下午块多为 90 分钟）不再只给一行提示：
  导入预览里逐块给出"保留课间、差值平分到单节"的推算结果，默认按文件更新作息，也可保持当前作息。
- 推算不出合理解（单节会短于 10 分钟或长于 4 小时）时不做猜测，保留课程钟点并提示手动调整作息。
- 选择后会与相邻节次一起校验重叠，冲突时禁用导入并说明，避免写入不可用的作息表。

### 1.5.0 更新

- 修复无重复规则的 ICS 导入卡住、提醒备注覆盖节次，以及 UTC 时区和单双周解析错误。
- 自动读取课程的实际起止时间，课程详情、小组件、课前提醒及备份恢复保持一致。
- 普通 WakeUp 文件的连堂时长与现有作息一致时，按文件钟点自动更新作息表，保留单节时长和课间间隔；时长不一致或时间冲突时显示原因。
- 支持文件附带完整作息表；导入前预览课程、节次、钟点与无法识别的内容。
- 覆盖导入在同一数据库事务中保存课程和作息，失败时恢复旧数据；新增可空时间字段的数据库迁移保留旧安排。


**课表**
- 多套课表并行管理，一键切换当前课表（如「我的课表」「考研表」）
- 周次视图：上/下周滑动、任意周跳转；单双周、不连续周次（如 `1-3,5,7-20`）均支持
- 课表网格按「星期 × 节次」排布，同一时段多门课自动分栏（Lane）不重叠
- 自定义作息时间：每节课起止时间、节次名称可编辑（默认大学作息：上午 4 节 / 下午 4 节 / 晚上 4 节）
- 学期设置：开学日期、总周数、显示天数（如只显示工作日）、显示地点/教师等

**课程**
- 新建课程或从已有课程中选一门排到空位
- 每门课支持简称（网格/小组件用小字显示）、教师、颜色
- 上课地点下放到「每一节安排」，同一门课不同时段可位于不同教室
- 点击网格中的课程块直接编辑，空位点击快速添加

**调休与节假日**
- 内置节假日调休方案：放假区间不上课、补课日按「周几」的课表上课
- 支持手动覆盖某一天的课表（放假 / 补课 / 临时调整）

**数据导入导出**
- 备份/恢复：一键导出**全部课表**（作息 + 学期设置 + 课程 + 安排）为单个 JSON 文件，恢复时单事务整库原子替换
- 导入 `.ics`：兼容 WakeUp 导出与普通单次日程，按课程名称与教师合并安排；支持按周重复的间隔、次数、星期与排除日期
- 自动读取 ICS 的课程起止钟点与时区，节次优先从备注或课名读取，否则按当前作息的重叠时段匹配；课程详情、小组件、课前提醒与备份保留这些钟点
- 导入前预览课程、节次、钟点与未识别内容；带有完整作息的文件可一起导入作息表，无需手工逐节调整
- 备份格式带版本号，向前兼容旧版本（v1.1 / v1.3 / v1.4 均为可选项增量扩展，旧备份照常导入）

**桌面小组件**
- 标准 AOSP AppWidget（RemoteViews），实时显示「今日 / 下一有课日」的课程与下一节课提醒
- 跨 ROM 尺寸自适应：针对 OriginOS / MIUI / OneUI 等不同桌面各自的尺寸上报语义分别决策，绝不裁掉底部内容
- 自刷新闹钟驱动，系统事件（开机 / 覆盖安装 / 改时间 / 改时区）后自动重排

**课前提醒**
- 精确闹钟（`USE_EXACT_ALARM`）保证准点提醒，不因 Doze 被推迟
- 开机、覆盖升级、改时间/时区后自动重新排程

**外观与适配**
- 主题色：自定义种子色对整块暖橙调色板做**色相迁移**，卡片、蒙版、图标整体跟随
- 深色模式、HSV 取色器
- 国产 ROM 后台 / 自启动引导：逐厂商探测可跳转的设置页，引导用户放行自启动以保证提醒与小组件刷新

### ICS 中的上课时间与完整作息

`DTSTART` / `DTEND` 记录一次课的真实起止时间，`TZID` 或 UTC 标记会转换到课表的上海时区。
例如 `DESCRIPTION:第1 - 2节\n教室\n教师` 表示第 1–2 节连堂；也支持课名末尾的 `（第1–2节）`。
普通 ICS 不能确定连堂课中每一节和课间的边界，导入器分两种情况处理：

- **连堂总时长与当前作息一致** → 按文件的起止钟点整块平移，保留用户现有的单节长度与课间间隔，静默完成。
  例如第 1–2 节由 `08:00–09:40` 更新为 `08:20–10:00`，原有 45 分钟单节及 10 分钟课间不变。
- **连堂总时长不同**（WakeUp 常见：上午块 100 分钟、下午块 90 分钟，而默认作息全按 100 分钟）
  → 在导入预览里逐块给出推算结果，由用户确认。推算规则是**保留课间、把差值按节数平分到单节**，
  例如 `14:00–15:40` 的 45+10+45 对应文件 `14:30–16:00` 时得到 40+10+40。
  差值分不出合理解（单节会短于 10 分钟或长于 4 小时）时不给推算，只提示手动调整。

每块都可以选择"按文件更新作息"或"保持当前作息"（后者课程仍按文件钟点显示）。
选择后会与相邻节次一起校验，若更新后重叠则禁用导入并说明原因；被放弃的块保持原作息不变。
同一节次的钟点互相矛盾时不做统一，逐条显示原因，课程整体钟点仍单独保存。
未注明节次时，需要当前作息表中存在与该课时间重叠的节次；无法匹配时显示原因，不按 45 分钟猜测。

若生成器知道每一节课的准确作息，可在 `VCALENDAR` 下附加可选字段：

```text
X-ORANGE-PERIODS:1=08:20-09:05,2=09:15-10:00,3=10:20-11:05,4=11:15-12:00
```

节次从 1 开始连续排列，时间按 `HH:mm`，各节不能重叠。导入预览会显示作息节数，确认覆盖或新建后与课程在同一事务中保存。
该扩展可按 ICS 文本规则转义逗号、折叠长行；不识别此扩展的日历仍可读取标准事件。
手工修改课程节次后改用该节次的作息钟点；只修改名称、教师、地点或周次会保留导入钟点，也可在安排编辑页选择「改用作息时间表」。

测试覆盖单次日程、无限重复的学期截断、单双周、时区、嵌套提醒、折行、完整作息，以及四份匿名化文件的逐次上课记录对照。
Robolectric 测试还覆盖普通 WakeUp 文件经 Room 写入后作息编辑页订阅的仓库流、覆盖/新建课表与失败时的事务回滚。

## 构建与运行

项目**未包含 Gradle Wrapper**，请使用本机独立安装的 Gradle（示例为 8.13），并指定 Android SDK 路径。

```bash
# 编译 Debug 包
gradle :app:assembleDebug

# 出正式签名 Release 包
gradle :app:assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk

# 运行单元测试
gradle :app:testDebugUnitTest

# 安装到已连接设备（覆盖升级、保留数据）
adb install -r app/build/outputs/apk/release/app-release.apk
```

首次构建前请确认 `local.properties` 中的 `sdk.dir` 指向本机 Android SDK，且 JDK 17 已就绪。

### 签名

Release 签名从项目根目录的 `keystore.properties` 读取：

```properties
storeFile=keystore/chengzikb-release.jks
storePassword=********
keyAlias=chengzikb
keyPassword=********
```

该文件与 `keystore/` 目录已被 `.gitignore` 忽略，**不会也不应提交到仓库**。正式签名密钥一旦丢失，将无法再发布可覆盖升级的同签名版本，请务必自行离线备份。

若 `keystore.properties` 不存在，构建会自动退回 debug 签名，方便无密钥环境或他人克隆后照样出包（但装真机时与正式签名不一致，无法覆盖升级，需先卸载）。

## 数据与隐私

- App **不申请联网权限**，不含任何统计 / 广告 SDK。
- 所有课表数据仅存于本机 Room 数据库；导出备份文件由用户自行保存与分享。
- 申请的权限及用途：
  - `POST_NOTIFICATIONS`：发送课前提醒通知
  - `SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM`：准点触发课前提醒
  - `RECEIVE_BOOT_COMPLETED`：开机后重新排程提醒
